# CT-92 Démo locale : inscription à la lettre d'information
URL : http://localhost:8000/newsletter.html

## Étapes
1. Saisir « lecteur@exemple.fr » dans le champ Adresse e-mail
2. Cocher « Je souhaite recevoir la lettre »
3. Cliquer sur « S'inscrire »

## Résultats attendus
- La case « Je souhaite recevoir la lettre » est cochée
- Le message « Inscription enregistrée » s'affiche
