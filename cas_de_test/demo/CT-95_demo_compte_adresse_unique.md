# CT-95 Démo locale : création de compte avec une adresse unique
URL : http://localhost:8000/inscription.html
Enregistrer la session : demo

## Étapes
1. Saisir « Alfred » dans le champ Prénom
2. Saisir « alfred.{unique}@exemple.fr » dans le champ E-mail
3. Cliquer sur « Créer mon compte »

## Résultats attendus
- Le message « Compte créé pour alfred.{unique}@exemple.fr » s'affiche
