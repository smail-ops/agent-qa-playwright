# CT-93 Démo locale : clavier, survol, double-clic, clic droit et défilement
URL : http://localhost:8000/clavier_souris.html

## Étapes
1. Saisir « clavier » dans le champ Recherche, puis appuyer sur la touche Entrée
2. Survoler le menu « Catalogue », puis cliquer sur « Nouveautés »
3. Double-cliquer sur « Projet sans nom » pour le renommer
4. Faire un clic droit sur « Fichier rapport.pdf », puis fermer le menu avec la touche Échap
5. Faire défiler la page jusqu'en bas

## Résultats attendus
- « Résultats pour « clavier » : 3 produits » s'affiche
- « Rayon : Nouveautés » s'affiche
- « Projet renommé » s'affiche
- « Menu contextuel » s'affiche après le clic droit, puis « Menu fermé » après la touche Échap
- « Avis clients : 4,8 sur 5 » s'affiche en bas de la page
