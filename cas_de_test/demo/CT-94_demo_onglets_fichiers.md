# CT-94 Démo locale : nouvel onglet, fichier joint, glisser-déposer et composant fermé
URL : http://localhost:8000/onglets_fichiers.html

## Étapes
1. Cliquer sur « Ouvrir la fiche produit » : la fiche s'ouvre dans un nouvel onglet
2. Dans la fiche, cliquer sur « Ajouter au comparateur », puis revenir au premier onglet
3. Joindre le fichier « facture.txt » dans le champ Pièce jointe
4. Glisser la tâche « relire le cahier de tests » dans la colonne Terminé
5. Saisir « À relire lundi » dans la note interne, puis cliquer sur « Enregistrer la note »

## Résultats attendus
- « Ajouté au comparateur » s'affiche dans la fiche produit
- « Comparateur : 1 produit » s'affiche dans le premier onglet
- « Fichier reçu : facture.txt » s'affiche
- « Tâche terminée » s'affiche
- « Note enregistrée : À relire lundi » s'affiche
