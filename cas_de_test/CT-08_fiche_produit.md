# CT-08 Fiche d'un produit
URL : https://www.saucedemo.com/

## Préconditions
L'utilisateur « standard_user » existe, avec le mot de passe « secret_sauce ».

## Étapes
1. Saisir « standard_user » dans le champ Username
2. Saisir « secret_sauce » dans le champ Password
3. Cliquer sur le bouton Login
4. Cliquer sur le nom du produit « Sauce Labs Backpack »

## Résultats attendus
- La fiche du produit s'ouvre : l'URL contient « inventory-item »
- Le prix « $29.99 » s'affiche
- Le bouton « Back to products » s'affiche
