# CT-16 Photos des produits avec problem_user
URL : https://www.saucedemo.com/

## Préconditions
L'utilisateur « problem_user » existe, avec le mot de passe « secret_sauce ».
Ce cas se lance avec la vision : l'agent doit voir les photos des produits.

## Étapes
1. Saisir « problem_user » dans le champ Username
2. Saisir « secret_sauce » dans le champ Password
3. Cliquer sur le bouton Login

## Résultats attendus
- La page « Products » s'affiche
- Chaque produit affiche sa propre photo, qui correspond à son nom (sac à dos, lampe de vélo, t-shirt...)
