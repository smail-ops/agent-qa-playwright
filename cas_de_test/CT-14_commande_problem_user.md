# CT-14 Commande avec l'utilisateur problem_user

## Préconditions
L'utilisateur « problem_user » existe, avec le mot de passe « secret_sauce ».

## Étapes
1. Saisir « problem_user » dans le champ Username
2. Saisir « secret_sauce » dans le champ Password
3. Cliquer sur le bouton Login
4. Ajouter le produit « Sauce Labs Backpack » au panier
5. Ouvrir le panier, puis cliquer sur « Checkout »
6. Saisir « Jean » dans First Name, « Dupont » dans Last Name et « 75001 » dans Zip/Postal Code
7. Cliquer sur « Continue »
