# CT-07 Déconnexion
URL : https://www.saucedemo.com/

## Préconditions
L'utilisateur « standard_user » existe, avec le mot de passe « secret_sauce ».

## Étapes
1. Saisir « standard_user » dans le champ Username
2. Saisir « secret_sauce » dans le champ Password
3. Cliquer sur le bouton Login
4. Ouvrir le menu avec le bouton « Open Menu », en haut à gauche
5. Cliquer sur « Logout »

## Résultats attendus
- L'utilisateur revient sur la page de connexion : l'URL ne contient pas « inventory »
- Le texte « Products » ne s'affiche plus
