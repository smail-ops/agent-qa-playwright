# CT-09 Panier avec deux produits
URL : https://www.saucedemo.com/

## Préconditions
L'utilisateur « standard_user » existe, avec le mot de passe « secret_sauce ».

## Étapes
1. Saisir « standard_user » dans le champ Username
2. Saisir « secret_sauce » dans le champ Password
3. Cliquer sur le bouton Login
4. Ajouter le produit « Sauce Labs Backpack » au panier
5. Ajouter le produit « Sauce Labs Bolt T-Shirt » au panier
6. Ouvrir le panier

## Résultats attendus
- L'URL contient « cart »
- Le panier contient « Sauce Labs Backpack » et « Sauce Labs Bolt T-Shirt »
- Le produit « Sauce Labs Onesie », non ajouté, ne s'affiche pas
