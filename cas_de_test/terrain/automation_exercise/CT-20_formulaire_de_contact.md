# CT-20 Envoi du formulaire de contact
URL : https://automationexercise.com/contact_us

## Étapes
1. Si une fenêtre de consentement aux cookies s'affiche, cliquer sur « Consent » (ou « Autoriser »)
2. Saisir « Alfred » dans le champ Name
3. Saisir « alfred.campagne@example.com » dans le champ Email
4. Saisir « Campagne de test » dans le champ Subject
5. Saisir « Message envoyé par l'agent de test. » dans le champ Your Message Here
6. Cliquer sur le bouton « Submit »
7. Confirmer l'envoi en cliquant sur « OK » dans la fenêtre de confirmation du navigateur

## Résultats attendus
- Le message « Success! Your details have been submitted successfully. » s'affiche
- Le bouton « Home » s'affiche sous le message
