# CT-18 Quantité d'un produit reprise dans le panier
URL : https://automationexercise.com/product_details/1

## Préconditions
Le panier est vide : chaque exécution démarre dans un navigateur neuf.

## Étapes
1. Si une fenêtre de consentement aux cookies s'affiche, cliquer sur « Consent » (ou « Autoriser »)
2. Remplacer la quantité par « 4 » dans le champ Quantity
3. Cliquer sur le bouton « Add to cart »
4. Dans la fenêtre « Added! », cliquer sur le lien « View Cart »

## Résultats attendus
- Le panier s'affiche : l'URL contient « view_cart »
- Le panier contient le produit « Blue Top », au prix de « Rs. 500 »
- Le total de la ligne est « Rs. 2000 »
