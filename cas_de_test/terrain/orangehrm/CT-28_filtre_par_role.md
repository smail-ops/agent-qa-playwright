# CT-28 Filtre des utilisateurs par rôle
URL : https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

## Préconditions
Le compte de démonstration « Admin » existe, avec le mot de passe « admin123 ».

## Étapes
1. Saisir « Admin » dans le champ Username
2. Saisir « admin123 » dans le champ Password
3. Cliquer sur le bouton « Login »
4. Cliquer sur le menu « Admin »
5. Dans le bloc « System Users », choisir « ESS » dans la liste « User Role »
6. Cliquer sur le bouton « Search »

## Résultats attendus
- La liste « User Role » indique « ESS »
- Le tableau n'affiche que des utilisateurs dont le rôle est « ESS »
