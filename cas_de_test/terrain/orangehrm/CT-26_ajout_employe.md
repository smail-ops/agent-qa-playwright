# CT-26 Ajout d'un employé
URL : https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

## Préconditions
Le compte de démonstration « Admin » existe, avec le mot de passe « admin123 ».

## Étapes
1. Saisir « Admin » dans le champ Username
2. Saisir « admin123 » dans le champ Password
3. Cliquer sur le bouton « Login »
4. Cliquer sur le menu « PIM »
5. Cliquer sur « Add Employee »
6. Saisir « Alfred » dans le champ First Name
7. Saisir « Campagne » dans le champ Last Name
8. Cliquer sur le bouton « Save »

## Résultats attendus
- La fiche de l'employé s'ouvre : l'URL contient « viewPersonalDetails »
- Le titre « Personal Details » s'affiche
- Le champ First Name contient « Alfred »
