# CT-29 Connexion à la zone sécurisée
URL : https://the-internet.herokuapp.com/login

## Préconditions
L'utilisateur « tomsmith » existe, avec le mot de passe « SuperSecretPassword! » (ils sont rappelés sur la page).

## Étapes
1. Saisir « tomsmith » dans le champ Username
2. Saisir « SuperSecretPassword! » dans le champ Password
3. Cliquer sur le bouton « Login »

## Résultats attendus
- Le message « You logged into a secure area! » s'affiche
- L'URL contient « /secure »
- Le bouton « Logout » s'affiche
