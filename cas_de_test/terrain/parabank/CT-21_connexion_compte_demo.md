# CT-21 Connexion avec le compte de démonstration
URL : https://parabank.parasoft.com/parabank/index.htm

## Préconditions
Le client de démonstration « john » existe, avec le mot de passe « demo ».

## Étapes
1. Dans le bloc « Customer Login », saisir « john » dans le champ Username
2. Saisir « demo » dans le champ Password
3. Cliquer sur le bouton « Log In »

## Résultats attendus
- La page des comptes s'affiche : l'URL contient « overview.htm »
- Le titre « Accounts Overview » s'affiche
- Le tableau des comptes se termine par la ligne « Total »
