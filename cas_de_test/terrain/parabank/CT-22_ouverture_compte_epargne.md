# CT-22 Ouverture d'un compte épargne
URL : https://parabank.parasoft.com/parabank/index.htm

## Préconditions
Le client de démonstration « john » existe, avec le mot de passe « demo », et possède au moins un compte.

## Étapes
1. Dans le bloc « Customer Login », saisir « john » dans le champ Username
2. Saisir « demo » dans le champ Password
3. Cliquer sur le bouton « Log In »
4. Cliquer sur le lien « Open New Account »
5. Choisir « SAVINGS » dans la liste du type de compte
6. Garder le compte proposé pour le dépôt initial
7. Cliquer sur le bouton « Open New Account », sous le formulaire

## Résultats attendus
- Le titre « Account Opened! » s'affiche
- Le message « Congratulations, your account is now open. » s'affiche
- Le numéro du nouveau compte s'affiche après « Your new account number »
