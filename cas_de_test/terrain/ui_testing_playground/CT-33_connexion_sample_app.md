# CT-33 Connexion à l'application exemple
URL : http://uitestingplayground.com/sampleapp

## Préconditions
L'application accepte tout nom d'utilisateur non vide avec le mot de passe « pwd ».

## Étapes
1. Saisir « Alfred » dans le champ User Name
2. Saisir « pwd » dans le champ du mot de passe
3. Cliquer sur le bouton « Log In »

## Résultats attendus
- Le message « Welcome, Alfred! » s'affiche
- Le bouton s'appelle désormais « Log Out »
