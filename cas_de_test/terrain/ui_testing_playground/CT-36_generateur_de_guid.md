# CT-36 Génération d'un identifiant GUID
URL : http://uitestingplayground.com/shadowdom

## Étapes
1. Dans le bloc « GUID Generator », cliquer sur le bouton de génération (icône d'engrenage), à droite du champ

## Résultats attendus
- Le champ du générateur affiche un GUID, au format xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx (chiffres et lettres de a à f)
